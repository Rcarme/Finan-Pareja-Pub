# Política de Seguridad / Security Policy

## Versiones Soportadas / Supported Versions

Nos tomamos muy en serio la seguridad y la privacidad de las finanzas personales y del hogar. Las actualizaciones de seguridad se aplican activamente sobre la rama principal:

| Versión / Rama | Soportada |
| --- | --- |
| `main` (v1.x) | :white_check_mark: Sí / Yes |
| Versiones anteriores | :x: No |

---

## 🇪🇸 Reportar una Vulnerabilidad

Si descubrís una vulnerabilidad o fallo de seguridad en este proyecto:

1. **NO abras un Issue público** describiendo la vulnerabilidad.
2. Utilizá la función nativa de **Advisories Privados de GitHub**:
   - Ingresá a la pestaña **Security** del repositorio en GitHub.
   - Hacé clic en **"Report a vulnerability"** para enviar un reporte privado y encriptado directamente a los mantenedores.
3. Alternativamente, podés enviar un correo electrónico privado a los mantenedores con los detalles técnicos del hallazgo y pasos para reproducirlo.

### Compromiso de Respuesta
- Confirmaremos la recepción de tu reporte dentro de las 48 horas hábiles.
- Evaluaremos el impacto y trabajaremos en una solución que se publicará de manera coordinada.
- Se te dará el debido crédito en las notas de la versión (si así lo deseás).

---

## 🇬🇧 Reporting a Vulnerability

If you discover a security vulnerability in this project:

1. **Please DO NOT create a public GitHub issue.**
2. Use GitHub's private vulnerability reporting feature:
   - Go to the **Security** tab of this repository.
   - Click on **"Report a vulnerability"** to submit an encrypted report directly to the maintainers.
3. We will acknowledge receipt within 48 hours and work with you to patch and disclose the issue responsibly.
